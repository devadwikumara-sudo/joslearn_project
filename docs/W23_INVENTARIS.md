## Catatan Pemetaan Akhir W23

1. **Sidebar Admin (8 Item Datar):**
   - Dashboard (`admin.dashboard`)
   - Data Siswa (`admin.data-siswa`)
   - Import Data (`admin.import`)
   - Kenaikan & Mutasi (`admin.kenaikan-mutasi`)
   - Alumni (`admin.alumni`)
   - Guru & Master (`admin.guru-master`)
   - Laporan (`admin.laporan`)
   - Setting (`admin.setting`)
   *Tidak ada sub-menu atau accordion.*

2. **Sidebar Guru (Maksimal 5 Item Datar):**
   - Beranda (`guru.beranda`)
   - Data Siswa (`guru.data-siswa`)
   - Input Nilai Mapel (`guru.input-nilai-mapel`) — hanya untuk guru mapel yang bukan wali
   - Import Data (`guru.import-data`) — untuk guru mapel dan/atau wali kelas
   - Kenaikan Kelas (`guru.kenaikan-mutasi?tab=kenaikan`) — hanya untuk wali kelas
   - Setting (`guru.setting`)
   *Di setiap kombinasi hak akses guru, jumlah menu tidak pernah melebihi 5 item.*

3. **Status Siswa Aktif vs Alumni:**
   - Siswa Aktif dikelola di menu `Data Siswa` (`admin.data-siswa`).
   - Siswa yang telah lulus dikelola di menu `Alumni` (`admin.alumni`) beserta catatan kelengkapan Kontrol Induk dan Pelacakan Alumni.
   - Mutasi keluar/masuk dikelola di menu `Kenaikan & Mutasi` tab Mutasi (`admin.kenaikan-mutasi?tab=mutasi`).
