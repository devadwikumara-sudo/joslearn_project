# Inventaris Halaman W23

Inventaris ini mencatat halaman admin dan guru yang benar-benar terdaftar di `routes/web.php`, termasuk halaman detail, halaman hasil impor, serta URL impor lama yang sekarang mengarah ke halaman gabungan. Kolom fitur menggambarkan kondisi saat ini; kolom terakhir adalah tujuan penggabungan W23, bukan perubahan yang dikerjakan pada langkah inventaris ini.

## Catatan pemetaan

- Sidebar admin kini memuat 10 tautan datar; Form Pendataan berada di panel Data Siswa, Kenaikan Kelas dan Mutasi Siswa memakai satu item Kenaikan & Mutasi, Log Aktivitas dan Tempat Sampah berada di bawah satu item Setting, dan kedua halaman Alumni lama memakai satu item Alumni. Menu Kenaikan Kelas guru tetap hanya tampil untuk wali kelas.
- Halaman Import Data admin berada di `/admin/import`, menggunakan `?tab=` dan hanya merender partial tab aktif. Route halaman impor lama dan detail hasil batch mengarah ke halaman gabungan; route template lama tetap dapat diunduh. Halaman gabungan guru membatasi tab/template dengan `AksesGuru`; URL lama GET/POST hanya redirect, dan penyimpanan tetap melalui endpoint batch yang memeriksa hak akses.
- Setting admin memakai `?tab=profil|tahun-ajaran|cadangan|sampah|log|akun` dan hanya merender partial aktif. URL halaman lama Log Aktivitas dan Tempat Sampah mengarah ke tab terkait; route ekspor CSV dan aksi pulih/hapus tetap bekerja. Setting guru dan Log Aktivitas guru tetap terpisah karena keduanya sudah tersedia dengan log yang dibatasi ke akun guru tersebut.
- View `admin/alumni.php` dan `admin/siswa-detail-content.php` sudah dibersihkan dari marker konflik saat penggabungan Alumni. `admin/siswa-detail.php` dan `guru/data-siswa-detail.php` masih perlu diperiksa sebelum langkah penggabungan Data Siswa.
